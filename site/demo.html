1. Run it on Qollab

The Qollab project runs in your browser on Pyodide, with no server. Press Run, pick a backend, fill in the form, and it:

  1. 01
    builds the molecular Hamiltonian for the bond length you type, live with PySCF, and prints the Hartree–Fock and exact FCI energies;
  2. 02
    generates the circuit with the trained model (NumPy, about 20 ms), with zero quantum evaluations to propose it;
  3. 03
    scores it exactly against FCI, next to kernel-ridge regression, nearest-neighbour reuse and a live ADAPT-VQE run with the quantum evaluations ADAPT needed;
  4. 04
    measures its energy on the backend you chose, with every measurement basis packed onto separate qubits of one circuit (H₂: 2 groups on 4 qubits), because Qollab's IonQ gateway takes one single-circuit job per run.
The run form · def main(system: str, r: float, a: float, b: float, shots: int, live_adapt: bool)

live_adaptAlso run ADAPT-VQE for the cost comparison
  • Backend. The built-in simulator (instant) or a free IonQ noise-model simulator (Forte 1, Aria); IonQ takes about 15 s. Paid hardware is never needed.
  • IonQ fits H₂ only. Packed measurement needs groups × qubits ≤ 29; the other systems need more, and the program says so. Use the built-in simulator for them.
  • Browser. Qollab needs WebAssembly JSPI (recent Chrome or Edge). If a second run straight after another fails with "file was not loaded … I/O error", reload the page and run again.
  • Measured. H₂ at r = 1.33 Å took 6.3 s end to end on the built-in simulator and 18.2 s on the IonQ Forte 1 simulator (IonQ 11.8 s), with live PySCF 0.3 s and the NumPy transformer 20 ms.

2. The workbench, for any small molecule

The repository also ships a local Streamlit workbench (streamlit run app/workbench.py) built around the same idea. Enter a molecule as a preset, SMILES, XYZ or coordinates; it builds the active-space Hamiltonian, decides whether a trained model actually covers the problem, proposes a complete circuit, grades it independently, optionally optimises it, runs it on a simulator or IonQ's cloud simulators, and exports everything.

StepWhat happensCode
MoleculePreset, SMILES (RDKit ETKDGv3, seeded conformers, optional MMFF/UFF), XYZ (kept verbatim) or atom table; charge, multiplicity, basis, frozen core, active space and mapping, all validated. Open shells use ROHF.genqai/molecule.py
Capability reportFormula, electrons, qubits, whether exact FCI is feasible, packed IonQ width. "Input accepted", "Hamiltonian built", "trained model covers it", "fallback available" and "backend can run it" are separate answers.molecule.assess
HamiltonianFrozen-core active space from one RHF, FCI by sector diagonalisation, CCSD where available. Presets reproduce the committed data exactly.genqai/chemistry.py
RoutingA: a trained model covers it, inside the validated range. B: compatible but out of range, labelled experimental, refine or ADAPT recommended. C: no compatible model, so ADAPT or UCCSD runs. D: too big, with suggestions instead of a silently smaller problem. The default method is the best on validation, which is kernel ridge on every trained system.genqai/registry.py
GenerateTransformer (SFT / GRPO / budget), kernel ridge, nearest-neighbour, ADAPT, UCCSD, with "+refine" and best-of-K; each run logs forward passes, candidates and quantum evaluations to propose.genqai/generate.py
GradeValidity (qubits, operators, finite angles, norm, particle number and Sz, no energy below the exact ground state) and accuracy against FCI, or labelled unverified; then resources (gates, CX, depth, IonQ-native counts, measurement groups, shots for a target error) ranked on a Pareto front among circuits that meet the target.genqai/grading.py
OptimiseAngle refinement, exact merging of repeated operators, operator pruning with re-refinement, transpiler level 3, noise-aware selection. The original is kept.genqai/optimize.py
ExecuteStatevector, local shots, local noisy (our own approximation), IonQ cloud simulators (ideal, Forte 1, Aria 1). Width is checked before anything is submitted.genqai/execution.py
ExportQiskit script (reproduces the statevector to 10⁻¹⁰), OpenQASM 2/3, Hamiltonian and metadata JSON, measurement and benchmark CSV; experiments saved locally with a configuration hash.genqai/export.py

Worked examples that run end to end: HeH⁺ from XYZ, water from SMILES and the OH radical (open shell) go to path C, and ADAPT reaches FCI on each (table). H₂ typed in by hand along any axis is recognised as the trained H₂ family (path A, kernel ridge). LiH beyond 4 Å goes to path B, labelled experimental. The test suite: 222 passed, 4 skipped.
